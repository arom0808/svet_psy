# Svet Psy — Личный сайт психолога

Мини-проект (разработан около 5 лет назад), представляющий собой личный веб-сайт и платформу-блог для психолога. Основная задача проекта — презентация специалиста и публикация профессиональных статей.

## 🛠 Технологический стек

* **Backend:** PHP, [Laravel](https://laravel.com/)
* **Frontend:** [Blade](https://laravel.com/docs/blade) (шаблонизатор), [Tailwind CSS](https://tailwindcss.com/)
* **Сборка ассетов:** Laravel Mix (Webpack)
* **База данных:** MySQL / PostgreSQL (стандартная поддержка Laravel)

## 📌 Основной функционал

* Личная страница (визитка) с информацией о психологе и услугах.
* Блог/система управления контентом (CMS) для написания и публикации авторских статей.
* Административная часть для управления публикациями (реализована стандартными средствами Laravel).
